# Εξώφυλλα portfolio

Το όνομα του αρχείου ακολουθεί το όνομα της σελίδας. Το εξώφυλλο `wedding-2.html`, για παράδειγμα, είναι το `wedding-2.jpg` σε αυτόν τον φάκελο. Μόλις προστεθεί και γίνει Commit και Push στο GitHub Desktop, το site το εμφανίζει αυτόματα. Αν το αρχείο λείπει, παραμένει το σημερινό εξώφυλλο ή χρωματικό φόντο.

- Κατηγορίες: `wedding.jpg`, `baptism.jpg`, `travel.jpg`, `love-story.jpg`, `event.jpg`.
- Άλμπουμ: `wedding-1.jpg` έως `wedding-6.jpg`, `baptism-1.jpg` έως `baptism-9.jpg`, `love-story-1.jpg` έως `love-story-3.jpg`, `event-1.jpg` έως `event-3.jpg`.
- Travel: `travel-1.jpg`, `travel-2.png`, `travel-3.png`. Τα δύο τελευταία διατηρούν τη μορφή PNG των σημερινών εξωφύλλων.
- Νέες κατηγορίες και άλμπουμ: χρησιμοποιήστε το όνομα της αντίστοιχης σελίδας HTML με κατάληξη `.jpg`.

Η εικόνα πρέπει να είναι πραγματικό JPEG ή PNG σύμφωνα με την κατάληξη. Η αλλαγή ονόματος της κατάληξης δεν μετατρέπει τον τύπο της εικόνας. Κάντε `Commit to main` και κατόπιν `Push origin` στο GitHub Desktop.
