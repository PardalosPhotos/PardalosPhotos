# Airbnb – Real Estate

Ανεβάστε εδώ τις φωτογραφίες καταλυμάτων Airbnb και ακινήτων.

Υποστηρίζονται αρχεία `.jpg`, `.jpeg`, `.png` και `.webp`. Βάλτε τις εικόνες απευθείας σε αυτόν τον φάκελο, χωρίς υποφακέλους. Η σελίδα `airbnb-real-estate.html` τις εμφανίζει αυτόματα μετά τη δημοσίευση του GitHub Pages.
