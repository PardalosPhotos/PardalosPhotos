# Pardalos Photos & Videos — Website

Πρώτη έκδοση ιστοσελίδας για GitHub Pages.

## Ανέβασμα
Ανεβάστε ΟΛΑ τα περιεχόμενα αυτού του φακέλου στο repository `PardalosPhotos`, με το `index.html` στη ρίζα.

## Δομή
- index.html
- assets/css/style.css
- assets/js/script.js
- assets/images/... (βελτιστοποιημένες φωτογραφίες)

Οι συλλογές και οι φωτογραφίες μπορούν να αλλαχθούν αργότερα χωρίς να ξαναστηθεί η ιστοσελίδα από την αρχή.
